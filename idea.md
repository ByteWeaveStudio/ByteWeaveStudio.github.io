# 5. INTERACTION PHILOSOPHY

Every interaction should have a reason.

Use:

* Smooth scrolling
* Subtle parallax
* Scroll-triggered transitions
* Text reveals
* Image masking
* Hover states
* Gentle 3D movement
* Layer separation
* Morphing visual states
* Micro-interactions

Avoid:

* Scroll hijacking
* Excessive animation
* Constant movement
* Long loading animations
* Overly dramatic transitions
* Animations that interfere with reading
* Anything that makes the website feel like a game

The animation should feel expensive and intentional.

The visitor should notice the quality of the interaction without thinking:

> "Look at this animation!"
